How to get a token

GitHub → Settings → Developer settings → Fine-grained tokens → Generate. Give it access to just your magic-calendar repo, with Contents: Read and write (and Actions: Read and write if you want “apply now”). Paste it above — it stays in this browser only.

Panel updates on the next daily render, or immediately with “Save & apply now”.
